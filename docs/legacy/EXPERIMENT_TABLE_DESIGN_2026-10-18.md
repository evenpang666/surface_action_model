# VLA 安全避障论文：实验大表与评估方案

检索日期：2026-10-18。本文是**实验设计和结果填写模板**；`待测` 表示尚无结果，`N/A` 表示不适用。所有数值必须来自本项目统一协议下的实验，不把其他论文的数字搬入本表。

本项目主线是 **π0.5 + 动作条件的未来机器人表面点预测 + CBF-QP + FK 轨迹复核**，对应 [SurfaceActionModelPytorch](../../openpi/src/openpi/models_pytorch/surface_action_pytorch.py)、[实机执行器](../../real_scripts/run_ur7e_vla_safety_executor.py)及 [LIBERO 评估入口](../../scripts/evaluate_pi05_safety_decoder_on_libero.py)。建议主张围绕三个问题展开：**能否无碰撞完成任务；是否比当前几何/FK 前视更有价值；障碍增多时是否仍可用。**

## 1. 检索得到的方法与取舍

下表中的“主表/附表”是本项目的实验安排建议，不代表方法已在仓库中实现。“适配版”必须单独命名、公开修改，不能冒充原论文原样复现。

| 方法 | 时间/出处 | 原方法关注点 | 本项目中的安排与比较边界 | 原始来源 |
| --- | --- | --- | --- | --- |
| π0.5 | 2025 | 通用 VLA，生成操作动作 | **必做 baseline**；在相同任务数据上微调，关闭新增安全模块 | [论文](https://arxiv.org/abs/2504.16054) |
| OpenVLA / OpenVLA-OFT | 2024 / 2025 | 开源 VLA；OFT 优化微调与动作生成 | 跨 backbone 附表优先选 OFT；原始 OpenVLA 可选，避免重复堆模型 | [OpenVLA](https://arxiv.org/abs/2406.09246)、[OFT 论文](https://arxiv.org/abs/2502.19645)、[OFT 项目](https://openvla-oft.github.io/) |
| ACT | RSS 2023 | 动作分块的模仿学习，包含双臂任务 | 经典学习 baseline，放双臂附表；原版不是语言条件 VLA，语言泛化列不能直接比较 | [论文](https://www.roboticsproceedings.org/rss19/p016.pdf) |
| Diffusion Policy | RSS 2023 | 基于动作扩散的视觉模仿学习 | 经典生成策略 baseline；按任务训练，或明确标注语言条件扩展 | [论文](https://arxiv.org/abs/2303.04137) |
| APF（人工势场） | Khatib，IJRR 1986 | 基于势场的实时避障 | **经典避障对照**：用同一个 π0.5 名义动作，加机器人表面点斥力修正 | [作者原文](https://khatib.stanford.edu/publications/pdfs/Khatib_1986_IJRR.pdf) |
| CBF-QP | Ames 等，TAC 2017 | 将安全约束写入二次规划 | **必做控制对照**：只用当前机器人几何，与预测触发的 CBF 比较 | [论文](https://arxiv.org/abs/1609.06408) |
| cuRobo | 2023 技术报告 | 并行碰撞检测与机器人运动生成 | 可选强规划对照：跟踪 VLA 局部子目标；需报告目标不可达、规划超时与重规划成本 | [论文](https://arxiv.org/abs/2310.17274) |
| SafeVLA | NeurIPS 2025 Spotlight；2026 有修订 | CMDP/安全强化学习，对长时程移动操作做安全对齐 | 相关工作应覆盖；**不直接把移动操作结果与桌面机械臂比较**。若实现 π0.5 的约束 RL 版，应称“受 SafeVLA 启发的适配版”并单列训练预算 | [论文](https://arxiv.org/abs/2503.03480)、[官方代码](https://github.com/PKU-Alignment/SafeVLA) |
| AEGIS / VLSA | 2025-12 初稿；IROS 2026，2026-07 修订 | 即插即用 CBF 安全层，SafeLIBERO；论文当前几何约束主要针对末端 | **优先直接同类对照**；主表用共享感知的适配版隔离控制能力，附表再测作者完整感知链路 | [论文](https://arxiv.org/abs/2512.11891)、[官方代码](https://github.com/THU-RCSCT/vlsa-aegis)、[基准与项目](https://vlsa-aegis.github.io/) |
| Barrier Enhanced Flow Matching | 2026-07 预印本 | 在 flow matching 去噪过程中施加 barrier 修正，约束动作 chunk | **优先近期对照**；适配 π0.5 采样器，比较生成中修正与生成后修正。下文简称 BEFM，为本文表格缩写 | [论文](https://arxiv.org/abs/2607.29569)、[作者项目](https://kassra-sinaei.github.io/safe-vla-webpage/) |
| CoFreeVLA | 2026-01 初稿；2026-09 修订 | 短时程双臂自碰风险估计、动作门控与恢复 | 双臂附表优先考虑；其重点是臂间及抓持物碰撞，不能只测外部障碍就宣称全面优于它 | [论文](https://arxiv.org/abs/2601.21712) |
| CrossSafe | 2026-09 预印本 | 形态条件的潜空间 HJ 可达性安全过滤，双臂全身碰撞约束 | 较新扩展对照；若不做跨机器人实验，可选。训练数据、机器人模型及部署适配成本单列 | [论文](https://arxiv.org/abs/2609.28984) |

**建议先完成：π0.5-FT、Stop、APF、Current-body CBF、FK-lookahead CBF、AEGIS、BEFM、本方法及关键消融。** ACT、Diffusion Policy、OpenVLA-OFT 用于补充方法覆盖；SafeVLA、CoFreeVLA、CrossSafe 按任务适配程度加入。这里把 ACT、Diffusion Policy 视为经典学习对照，也有 [OpenVLA-OFT 项目的对照设置](https://openvla-oft.github.io/)作为参考；不把它们称为专门的安全避障方法。

### 2.1 各行如何定义

| ID | 实验实现约定 | 这一行回答的问题 |
| --- | --- | --- |
| B0 | 相同 π0.5 初始权重、演示数据、可训练范围及训练预算，只训练动作目标 | 没有新增安全机制时任务能力如何？ |
| B1 | 用 B4 相同 FK 前视风险判据，只做保持/停机；风险解除才恢复，等待计入总时限 | 单靠停机能否兼顾安全与任务完成？ |
| B2 | 用当前全臂几何算斥力，对 B0 动作修正；增益仅在验证集选择 | 预测模块是否优于经典反应式避障？ |
| B3 | 用当前全臂表面和相同 QP，只构建当前状态的距离约束 | 未来点预测相对当前几何的收益是多少？ |
| B4 | 展开 B0 名义 action chunk，通过 FK/控制器 rollout 得到未来表面，接相同 CBF 和复核 | **学习预测是否优于强模型几何前视？** 仿真中的状态克隆 rollout 成本必须计时 |
| B5 | 从 VLA chunk 提取局部子目标，规划后跟踪；不得使用人工分解好的任务目标 | 传统规划是否已经可以解决问题？ |
| R1 | 保留 AEGIS 控制结构，接统一感知输入；明确保留其末端约束范围 | 与近期 VLA 安全层相比如何？另报原生完整链路，区分感知与控制收益 |
| R2 | 在 π0.5 flow 采样中实施 barrier 修正；统一机器人模型、安全距离和采样预算 | 生成中安全引导与表面预测后过滤有何差别？ |
| O0 | 与 O2 **同一联合训练 checkpoint**，关闭新增安全模块及不再需要的预测计算 | 联合训练本身对动作质量有何影响？ |
| O1 | O0 同一 checkpoint，安全层用当前几何，不用学习到的未来点 | 排除动作专家微调差异后，预测是否仍有效？ |
| O2 | 使用学习到的未来表面筛选风险、CBF 修正，并进行 FK 复核；报告复核拒绝/保持次数 | 完整系统的任务、安全、时延表现 |

B0 与 O0 用于区分联合训练收益；O1 与 O2 用于隔离预测收益。还应在消融表加入 **O0 checkpoint + FK-lookahead**，让学习预测与 FK 在同一动作策略下直接比较。对 B3/B4/O1/O2 采用相同采样密度、QP 限制和最终复核规则；移除复核的影响在消融表单测。

## 6. 指标定义与统计口径

令 N 为全部启动的测试 episodes；Sᵢ 表示在时限内成功；Cᵢ 表示发生任意禁止碰撞。下表给出建议口径，所有方法统一使用。

| 指标 | 定义/计算方式 | 说明 |
| --- | --- | --- |
| **SR↑** | `100 × Σ Sᵢ / N` | 任务成功率；仿真使用任务原生成功判据，不能用回放到达优化终点替代 |
| **SSR↑** | `100 × Σ [Sᵢ 且非 Cᵢ] / N` | **主指标：无禁止碰撞完成率**；停机不完成计失败 |
| CR-env↓ | 至少发生一次机器人与外部环境禁止接触的 episode 比例 | 用全臂、末端、夹爪评估；不只测用于控制的稀疏点 |
| CR-self↓ | 至少发生一次禁止自碰/臂间碰撞的 episode 比例 | 相邻连杆的设计接触排除；单臂仍可评估非相邻连杆自碰 |
| CR-held↓ | 抓持物与环境、另一手臂或另一抓持物发生禁止接触的 episode 比例 | 与机器人直接碰撞分开记录；任务需要的物体放置接触按阶段允许 |
| CR-link↓ | 非末端连杆与障碍发生禁止接触的 episode 比例 | 专门验证表面/全臂覆盖的作用，是 CR-env 的子集 |
| CR-any↓ / CAR↑ | `100 × Σ Cᵢ / N`；`CAR = 100 − CR-any` | Cᵢ 是上述禁止碰撞事件的并集，各 CR 不能简单相加 |
| d05↑ | 先求每个 episode 的最小有符号间距，再取这些最小值的第 5 百分位 | 单位 mm；覆盖机器人、抓持物及禁止碰撞对；负值表示穿透。不等同于安全证明 |
| SVR↓ | 每 episode 中 `d(t)<δ` 的时长占比，再对 episodes 平均 | 安全距离违规率，δ 需固定；可以无接触但违反安全裕量 |
| Timeout↓ | 超过预定义时限的 episode 比例 | 另列停机未完成、求解失败、感知失败等互斥终止原因 |
| 完成时间↓ | 成功 episodes 的 wall-clock 时间，报告中位数/IQR | 连同 SR、Timeout 和全部 episode 时长报告，等待与重规划时间计入 |
| nΔa↓ | `mean ‖D⁻¹(a_exec − a_nominal)‖₂` | D 为预定义每维动作尺度；避免把 rad/m/夹爪量直接混成欧氏范数；关节与夹爪最好分报 |
| IR | 安全模块实际修改动作、保持或拒绝发送的控制周期比例 | 不等同于 QP 触发率；阈值固定，不作为单独胜负指标 |
| QP-fail↓ | 失败/不可行/超时的 QP 调用数占全部 QP 调用数 | 未调用 QP 时为 N/A，不能把“未触发”算成求解成功 |
| L95↓ | 从已同步观测可用到可执行动作获准发送的端到端时延 P95 | 含感知、传输、VLA、预测、安全控制与复核；另报各阶段 P50/P95 |
| DMR↓ | 实际控制/规划任务超过其约定 deadline 的比例 | 规划周期和 servo 周期分报；动作生成吞吐量不能代替闭环时延 |
| Point-ADE / FDE↓ | 有效且对应的表面点，在全部预测时刻/最后时刻的平均欧氏误差 | 单位 mm；按预测 horizon 分报，并公布有效点覆盖率 |
| 3D Point-RMSE↓ | `sqrt(mean ‖p_pred − p_gt‖₂²)`，只含有效点 | 是三维点距离 RMSE；不是单坐标 MSE 开方，见第 8 节 |
| 风险 AUPRC↑ / Recall↑ | 固定测试 action chunk 是否会发生禁止碰撞为标签，以最小预测距离等为连续风险分数 | 使用未加安全修正的 chunk 做固定评测；报告阳性比例，阈值仅在验证集选 |

碰撞真值优先用仿真引擎完整接触对，在每个物理子步累计；实机用独立视频标注、力/力矩及可获得的接触记录交叉核验，并公开接触阈值。**预测点进入感知 OBB 是风险信号，不是真实碰撞标签；感知 OBB 膨胀也不是实际障碍表面。** 用稠密几何/仿真真值算 d05 和 SVR，避免安全层用自己的近似几何评价自己。

## 7. 障碍数量与公平比较协议

1. **数量定义**：K∈{0,1,2,3,5} 表示人为新增的物理障碍实例数，不是检测器输出的 OBB 数、体素数或连通域数。主场景结构与任务物体保留；额外日志记录检测框数量和占据体积。
2. **布局控制**：每个 K 生成多个布局；障碍形状、体积、高度、起终点距离按分层规则抽样，所有方法共享相同任务、init state、布局、种子。可用嵌套布局（K=2 保留 K=1 的障碍），但不强制所有任务采用同一布局。
3. **区分数量与拥挤度**：主实验固定单体大小分布，让总占据体积随 K 增加；补充“固定总占据体积、改变 K”的实验。另报最窄通道宽度，不能把形状/尺寸变化全归因为数量。
4. **保证任务有解**：排除目标被完全封死、起始机器人已穿透等无解布局；在比较前统一用规划器/人工审核可行性，不能根据某方法是否成功来挑选布局。
5. **训练公平**：B0 与联合训练模型使用相同演示、初始化、训练数据切分和动作空间；训练时长、额外安全标签、参数量另报。主表的安全包装方法共享 B0 checkpoint；联合训练消融共享 O0 checkpoint。
6. **感知公平**：控制层比较统一 RGB-D、外参、机器人模型、障碍表示与安全距离。GT 输入仅作诊断；另外报告各方法原生感知的完整系统结果，不混合排名。
7. **控制公平**：固定动作维度、控制频率、动作/速度上限、执行前缀、任务时限与碰撞处理规则。仿真建议碰撞后继续至成功或时限，以分开观察 SR 和 SSR；引擎失稳按统一失败规则终止。实机统一接触即停，分别报受监测条件下的结果。主要结果采用可用的完整动作空间；若测仅平移版本，单列附表。不得只冻结其他方法的姿态自由度。
8. **预算公平**：相同 GPU/CPU、batch=1、warm-up、采样预算和 deadline；BEFM、FK rollout、cuRobo 的额外迭代全部计时。报告任务期间的停机/恢复成本。
9. **统计**：先按任务、再按套件和 K 宏平均，保存每个 episode 原始结果。每个率报告分子/分母；正文可写点估计与 95% CI，附表给配对差值的分层 bootstrap CI。不同训练种子的结果分别报告，再给 seed 间均值/标准差，不把控制帧当独立样本。
10. **完整性**：达到成功、预定义失败或时限才是完整 episode。采样数上限提前截断不能当成功/安全完成；预定义的系统失败计失败并报告。硬件日志损坏等无效试验按统一规则重跑并保留记录，不能只剔除失败方法的数据。

建议先做四套件各 2 个任务 × 5 个 K × 10 episodes = **400 episodes/方法**的试验阶段。正式仿真可选四套件各 5 个任务 × 5 个 K × 50 episodes = **5,000 episodes/方法/训练种子**；若预算允许使用全部套件任务。多个训练种子适用于学习策略，确定性安全包装可复用相应种子的 backbone。

实机先完成 6 任务 × K∈{0,1,3} × 每格 10 次 = **180 次/方法**的探索，再扩充核心方法到每格 20–30 次。少量试验只能给初步证据；即使 30 次零碰撞，也不能据此声称碰撞概率为零。正式测试前冻结样本量和布局清单。
